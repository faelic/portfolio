# Escrow — Sepolia payment learning project

**Type:** Independent learning project.  
**Contribution:** React frontend and Solidity smart contract.  
**Network:** Ethereum Sepolia, a test network.  
**Repository:** https://github.com/faelic/escrow-webapp

## Purpose and contribution

Escrow is Favour's independent learning project for a payment flow involving a depositor, beneficiary, and arbiter. Favour built both the React frontend and the Solidity smart contract. The arbiter can release or refund funds.

## Availability and further exploration

Escrow's frontend is not deployed. Visitors can explore its code and implementation in the [Escrow repository](https://github.com/faelic/escrow-webapp).
